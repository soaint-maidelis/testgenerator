# Requirements

- GS-001: A User Story candidate cannot generate code before explicit QA approval.
- GS-002: Generation plans are read-only and prioritize reuse.
- GS-003: Generation metrics contain only measured duration and actual component/file changes.
- GS-004: Core strategy dimensions are generic; application taxonomies remain application-owned.
- GS-005: Dependencies are validated for missing references and cycles.
- GS-006: Group selection lists matched case IDs before optional execution.
