# Requirements

- IN-001: InputAdapter exposes identity, supported extensions, detection, parsing, and normalization.
- IN-002: Excel accepts documented header aliases and reports row/field errors.
- IN-003: JSON accepts a single case, an array, or an object containing `cases`.
- IN-004: User Stories are parsed deterministically in English or Spanish.
- IN-005: User Story candidates always use `REQUIRES_QA_REVIEW`.
- IN-006: Every imported case retains optional source traceability.
- IN-007: Existing catalog validation remains authoritative and backward compatible.
- IN-008: Imports write previews only under `artifacts/input-preview`.
